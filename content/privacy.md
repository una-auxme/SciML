This website is a static site hosted on GitHub Pages. It sets no cookies, uses no analytics and loads
no fonts or scripts from third-party servers. GitHub, as the hosting provider, processes technical
access data (such as IP addresses) to deliver the website; see the
[GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## YouTube videos {#youtube}

Some pages show videos hosted on YouTube (Google Ireland Limited). The preview images are stored on
this website, so no data is sent to YouTube while you browse. Only when you click a video to play it is
the YouTube player loaded from youtube-nocookie.com. YouTube then receives technical data such as your
IP address and may set cookies; see the [Google Privacy Policy](https://policies.google.com/privacy).
