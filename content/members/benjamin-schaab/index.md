Benjamin wants to know how much a model can tell you about what it doesn't know. Given an imperfect
physics-based model and imperfect data, how much can still be squeezed out of the pair? Where in an
object-oriented model is the unmodeled physics hiding, and how many latent states does it drag along?
Which input features does the neural network need, and what loss function makes it actually learn
them instead of something more convenient? Because the model's object-oriented structure narrows the
search down to a single component, the network only has to learn the physics that is actually missing,
not the whole system from scratch. That makes these hybrid models easier to interpret and far less
hungry for data than their monolithic cousins.

He joined the Scientific Machine Learning group in 2026, and has been searching for the missing physics ever since.

Away from the keyboard, multi-pitch climbing and mountaineering keep his weekends as vertical as his loss landscapes, with the notable difference that there, he is after the global maximum, and getting stuck in a local one still comes with a view.
